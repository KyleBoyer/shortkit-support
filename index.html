ShortKit Support

Help for ShortKit on iPhone and iPad.

Get help

The fastest way to get help, report a bug, or suggest a feature is to open a GitHub issue. Requests are usually answered within a few days.

Open a support request Browse existing issues

Please don't post personal details. GitHub issues are public.

Helpful things to include:

  • Your device and OS version (for example, iPhone 16, iOS 27.2)
  • The app version (shown in the App Store listing)
  • What you did, what you expected, and what happened instead
  • A screenshot, if it helps

Frequently asked questions

Where are the actions?

Open the Shortcuts app, create or edit a shortcut, tap Add Action and search for ShortKit. The app's Actions tab lists every action and what it does.

What can the actions do?

ShortKit adds settings (get, set, delete, list and increment counters), list tools (sort and remove duplicates) and text tools (find and replace with regular expressions). List actions accept a list or multi-line text, one item per line.

Where are my settings stored?

Settings saved by the Set Setting action are stored as text on your device. You can browse, edit and delete them in the app's Settings tab.

An action failed with "Fail If Missing"

Get Setting stops the shortcut when the setting doesn't exist and Fail If Missing is on. Turn it off and give a default value, or set the value first.

Can't use GitHub?

If you can't open an issue, you can email the developer instead. GitHub issues get a faster reply.
